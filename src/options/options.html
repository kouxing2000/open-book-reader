How to use & shortcuts

Open it on any page — three ways:

  • Toolbar icon — smart pick: the 📖 reader for articles, the 🖼 gallery for image-heavy pages.
  • Right-click a page or image → Open in Book Reader → Smart pick / Reader / Gallery.
  • Keyboard: Alt+B reader · Alt+Shift+B gallery.

Want a site to always open one way? Right-click → Configure Default, or add a path/wildcard pattern under Per-site rules below. Want zero clicks? Right-click → Auto-open on this site — content pages there open by themselves, list pages never do, and Esc always closes.

While reading (📖 reader)

  • ← → flip pages — or click the left / right edge of the book
  • Home / End first / last spread · Esc close
  • Topbar: ⊞ columns (2/3/4) · theme · A− / A+ font size · 🖼 switch to gallery

Picked the wrong content? Sometimes the reader grabs a sidebar or the wrong block. Three ways to fix it:

  • Select the text on the page first, then open the reader — it reads just your selection.
  • Click ⌖ Pick in the topbar, then click the block you want — the reader re-reads from there.
  • After picking, Save for this site so it's reused automatically next time. Saved picks live under Saved content picks below, where you can fine-tune the CSS selector or remove them.

In the gallery (🖼 images)

  • Wall / Ordered layout toggle — Ordered reads images in order, row by row; Size at max = one page at a time (webtoons, manga)
  • Click a tile for the lightbox — ← → browse · Esc close
  • ⟷ Fit width in the lightbox reads a tall page by scrolling — F toggle
  • ▶ Auto-scroll hands-free browsing — A toggle · + / − speed
  • ⟳ Load all pulls lazy images · select tiles to download or ZIP · 📖 switch to reader
  • ⊘ Hide on a tile filters avatars & repeated noise (per site) — hover a scope to preview what disappears

Change the keyboard shortcuts

Chrome controls these — they can't be edited inside the extension. Open Chrome's shortcut editor to set your own.

🌐 Per-site data for specific sites
Per-site rules Force a mode on specific sites instead of the smart pick. The pattern matches host + path with * as a wildcard — example.com (whole site), example.com/blog/* (a section), *.example.com/* (all subdomains). When several match, the most specific wins. Applies to the toolbar icon and right-click menu; Alt+B / Alt+Shift+B always honor their own mode. Auto-open goes one step further: matching pages that look like real content (an article body, an image set) open in reading mode with no click at all — list and search pages stay untouched, and Esc always closes. It asks once for permission to run on that site.
Site access The sites this extension may read, as Chrome records them — you granted them by turning on auto-open or by downloading gallery images. Image downloads ask only for the sites those images come from; if you chose Allow all sites instead, that single grant covers everything listed here and makes the individual rows redundant. Revoking is instant and safe — the extension simply asks again next time you use the feature. You can also manage the same list in Chrome at chrome://extensions. Chrome keeps a record of sites it has asked about: one listed there with its toggle off has no access — that entry is history, not permission.
Saved content picks When the reader grabs the wrong block, the ⌖ Pick button lets you choose the real content and Save for this site. Saved picks are listed here and reused automatically on that site. You can edit the CSS selector to fine-tune it: a class like .article-body is more robust than the auto-generated path, and a selector that matches several blocks (e.g. .intro, .post-body) reads them all. The ✓/✗ marks whether the selector is valid. Remove one to go back to automatic extraction.
Hidden images The per-site image filter. The ⊘ Hide button in the gallery drops an image (or its folder / host) from the wall — useful for avatars, badges and other repeated noise. Hidden patterns are listed here as URL globs (* = wildcard). Entries starting with css: match images by their place in the page instead of by URL. Remove one to bring those images back.

Privacy: collects no data and sends nothing to the developer. It runs on a page only when you invoke it (toolbar icon, shortcut, or right-click menu) — or on sites where you explicitly turned auto-open on. It makes network requests only when you explicitly download images from the gallery.

Open source: this extension is fully open — read every line, verify the privacy claims, file an issue, or contribute at github.com/kouxing2000/open-book-reader.
